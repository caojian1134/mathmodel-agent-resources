# Security Policy

This repository is a directory of links and metadata. It does not endorse or automatically execute third-party projects.

Before installing any linked Agent or Skill:

1. inspect its instructions and scripts;
2. review network, subprocess, deletion and overwrite behavior;
3. use an isolated environment and disposable workspace;
4. avoid placing secrets in configuration files or shell history;
5. verify outputs independently.

To report a security concern about this directory, open an Issue without publishing credentials, exploit payloads or private data. Vulnerabilities in a linked project should also be reported to that project's maintainers.
