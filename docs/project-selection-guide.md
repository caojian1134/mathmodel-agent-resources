# Project Selection Guide / 项目选择指南

[English](#english-guide) | [中文](#中文指南)

This guide helps users narrow down the 32 projects by task. It is a navigation aid, not a quality ranking, security certification, or claim that a project complies with current contest rules.

## English guide

### Choose by outcome

| Desired outcome | Start with | Why |
|---|---|---|
| Organize an end-to-end contest workflow | handsomeZR `mathmodel-skill`, Hjdd14 `math-modeling`, xuec699 `math-modeling-skills` | Their reviewed descriptions emphasize staged work, checkpoints, evidence, or quality gates. |
| Assemble several specialist roles | `math-model-agent`, `MathModel-Skill`, `MathModelAgent`, `MathModeling-skills` | They package multiple skills or roles rather than a single prompt. |
| Study open-ended modeling agents | `ModelingAgent`, `LLM-MM-Agent` | They focus on decomposing and solving open-ended modeling problems. |
| Formulate and validate optimization models | `ORLM`, `ReSocratic`, `solver-in-the-loop`, `LLM4OPT` | They focus on mathematical programming, optimization reasoning, solver feedback, or related resources. |
| Benchmark a data-analysis agent | `AgenticDataBench` | It provides data-analysis-agent tasks and evaluation material. |
| Find executable algorithm examples | `MathematicalModelingAlgorithm`, `CUMCM` | They provide Python or MATLAB-oriented modeling examples. |
| Prepare a contest paper | The five template projects | They target CUMCM or MCM/ICM typesetting; always compare them with current official rules. |
| Practice with historical problems | `cumcm-problems` | It organizes CUMCM problems and attachments by year. |

## 中文指南

### 按目标选择

| 目标 | 建议先看 | 选择理由 |
|---|---|---|
| 组织从审题到交付的完整流程 | handsomeZR `mathmodel-skill`、Hjdd14 `math-modeling`、xuec699 `math-modeling-skills` | 已检查说明强调阶段、检查点、证据或质量门。 |
| 组合多个专业角色 | `math-model-agent`、`MathModel-Skill`、`MathModelAgent`、`MathModeling-skills` | 这些项目组织了多个 Skill 或角色，而不是单一提示词。 |
| 研究开放式建模 Agent | `ModelingAgent`、`LLM-MM-Agent` | 核心是开放式问题分解、建模、计算和报告。 |
| 建立并验证优化模型 | `ORLM`、`ReSocratic`、`solver-in-the-loop`、`LLM4OPT` | 重点涉及数学规划、优化推理、求解器反馈或相关资源。 |
| 评测数据分析 Agent | `AgenticDataBench` | 提供数据分析 Agent 的任务和评测材料。 |
| 查找可执行算法示例 | `MathematicalModelingAlgorithm`、`CUMCM` | 分别偏向 Python 与 MATLAB 建模示例。 |
| 准备竞赛论文 | 5 个模板项目 | 分别面向 CUMCM 或 MCM/ICM；必须再与当届规则核对。 |
| 使用历年赛题练习 | `cumcm-problems` | 按年份组织 CUMCM 题目和附件。 |

上表中的“主要用途”和“比赛倾向”是目录级导航标签，不代表已经完成端到端运行验收。正式采用项目前，还应检查依赖、命令权限、网络行为、许可证、最近维护状态和目标比赛规则。

### 最小采用检查表

- [ ] 阅读上游 README、安装脚本和全部 `SKILL.md`；
- [ ] 核对许可证是否允许计划中的使用和分发方式；
- [ ] 在隔离环境用最小样例测试，不直接运行未知高权限脚本；
- [ ] 核对输入、输出、随机种子、依赖和失败条件；
- [ ] 用确定性工具或独立脚本复算关键数字；
- [ ] 核对当届 AI 使用与披露规则。
