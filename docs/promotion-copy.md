### 正文

因此，我建立了开源目录 **MathModel Agent Resources**，目前收录 32 个公开项目，并按六类整理：开放式数学建模 Agent，竞赛 Skills/Agent/Starter，优化与评测工具，算法代码，排版模板，以及历年赛题与附件。

项目地址：https://github.com/caojian1134/mathmodel-agent-resources

如果你维护相关项目，欢迎提交 Issue 或 PR 更正介绍、补充测试与许可证信息；如果这个目录节省了检索时间，也欢迎 Star，让更多建模队伍能够发现它。
